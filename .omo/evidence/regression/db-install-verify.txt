=== ADDENDUM: pkg query format correction ===
The task brief specified:  pkg query "%Ok %Ov" mariadb-server postgresql-server
That format string is WRONG for "origin + version":
  %Ok -> OPTIONS KEY (e.g. AWS_KEY_MGMT)
  %Ov -> OPTIONS VALUE (e.g. on)
  %o  -> origin (e.g. databases/mariadb114-server)
  %v  -> version (e.g. 11.4.12)
Correct query:  pkg query "%o %v" mariadb114-server postgresql16-server
Result:
databases/mariadb114-server 11.4.12
databases/postgresql16-server 16.14
